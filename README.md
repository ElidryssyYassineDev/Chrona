# Chrona

> Production-grade Workforce Management Platform built with Domain-Driven Design and Modern .NET.

## Overview

Chrona is a self-hosted, multi-tenant workforce management platform designed for organizations with approximately 20–100 employees.

Its purpose is to help organizations:

- Plan work
- Allocate employees
- Track time
- Manage leave
- Execute approval workflows
- Analyze workforce utilization

Chrona is built as a long-term engineering project focused on production-quality architecture and software engineering practices.

---

## Project Goals

- Learn enterprise software engineering
- Apply Domain-Driven Design
- Build a Modular Monolith
- Practice Clean Architecture
- Implement Vertical Slice Architecture
- Produce production-quality code
- Document architectural decisions
